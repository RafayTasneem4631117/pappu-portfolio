# assets/projects/hunted-hunter/

| File | Status | What it is |
|------|--------|------------|
| cover.jpg | ✅ present | the image on the project card (don't rename) |
| project.pdf | ⬜ **add your PDF here** | shown inside the website (viewer window) when the card is clicked |

The website looks for exactly `assets/projects/hunted-hunter/project.pdf`.
If your PDF has a different name, either rename it to `project.pdf`, or change the
`pdf:` line for this project in `frontend/src/data/projects.js`.
Until the file exists, the viewer window shows a "PDF isn't available yet" message.
