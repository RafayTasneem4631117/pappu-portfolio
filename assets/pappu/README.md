# assets/pappu/

Pappu artwork cut out of your Illustrator file (transparent PNGs):

- pappu-hi.png       — the clickable Pappu next to "Hi!" (opens the chatbot)
- pappu-glasses.png  — "Things I'm learning"
- pappu-easel.png    — beside the Revision card
- pappu-popcorn.png  — "In motion"

Composite doodles that include a Pappu live in `assets/doodles/` (car-pappu.png, idea-pappu.png).
Better quality? Export SVGs from Illustrator (File ▸ Export ▸ Export As… ▸ SVG) and
replace the PNGs (keep the same file names, or update the paths in the components).
