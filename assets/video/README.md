# assets/video/

Put your promotional video here as **promo.mp4**.
The website picks it up automatically — no code changes needed.
(To use another name/path, edit `video.src` in `frontend/src/data/site.js`.)

Tips: H.264 video + AAC audio in an .mp4 plays everywhere. Keep it under ~30 MB for fast loading.
Optional poster image: `poster.jpg` (then set `video.poster` in site.js).

Until the file exists, the page shows a placeholder note — no fake video is used.
